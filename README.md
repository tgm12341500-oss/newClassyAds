# ClassyAds | Classified Advertising Platform

A modern multi-page front-end website designed to provide a structured and intuitive interface for browsing classified advertisements.

## Overview

ClassyAds is a front-end web development project that presents a classified advertising platform through a clean and organized user interface. The website is structured into dedicated pages to support clear navigation and a consistent browsing experience.

## Website Sections

- **Home:** Main landing page.
- **Ads:** Advertisements browsing page.
- **About:** Information about the platform.
- **Blog:** Blog content section.
- **Contact:** Contact page.
- **Log In:** User login interface.
- **Register:** User registration interface.

## Technologies & Tools

- HTML5
- CSS3
- Bootstrap
- JavaScript

## Project Structure

The project is organized into separate directories, with each directory containing the files related to a specific website section.

## Getting Started

To view the project locally:

1. Clone or download this repository.
2. Open the project directory.
3. Navigate to the `Home` folder.
4. Open `index.html` in your web browser.
